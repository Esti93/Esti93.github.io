# Portfolio editing instructions

Maintain Esti’s graphic and UI design portfolio. Start each task by checking the current branch, working changes, and files relevant to the request. Preserve manual edits. Use repository-local Git identity on this shared Mac.

Keep the starter in plain HTML and shared CSS until Esti requests a refactor. Use relative links. Use projects/<slug>/index.html for each project, assets/images/<slug>/ for its images, and templates/project.md for the editing pattern. Update the Work gallery and any featured home entry. Keep navigation consistent on every page. Use Esti’s supplied copy, role and project facts. Ask for missing material when needed.

For Figma requests, inspect the specified frames and use web-sized exports with descriptive alt text. Keep editable source designs in Figma. Use UI UX Pro Max and 21st.dev MCP when available for relevant design tasks. Keep their configuration, credentials and dependencies out of the visitor-facing site.

Check affected links, desktop and mobile layout, keyboard focus and asset sizes. Report progress against the task roadmap. Distinguish local edits, commits and live deployments in updates. When asked to publish, sync with main and verify the live Pages URL.
