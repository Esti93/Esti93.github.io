# Esti’s portfolio

Open index.html to view the site locally. The home page links to projects/polti.html. Both use style.css. The live site is intended for https://esti93.github.io/ using the root of main as the GitHub Pages publishing source.

## Editing by prompt

Open this repository folder as a local Codex project. AGENTS.md supplies the working instructions. A typical request is “Use these two Polti Figma frames to add a wireframe and final design to the Polti page. Preview the result on mobile.”

For a ChatGPT Project, use this project instruction: “Maintain Esti93/Esti93.github.io. Read its current AGENTS.md at the beginning of each editing task. Use the GitHub connection for repository access and the Figma connection for any supplied frame links.” Open the folder in Codex whenever edits should also be made on this Mac.
