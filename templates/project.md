# Adding a project

Create projects/<project-name>/index.html using projects/polti/index.html as the structural reference. Place optimized, public images in assets/images/<project-name>/. Keep the project title, role, copy, credits and external links specific to the new project.

Use a cover, short brief, role and scope, and the strongest evidence of the designer’s work. Add a wireframe-to-final comparison when source frames are available. Link the project from work/index.html and feature it on index.html when requested.
